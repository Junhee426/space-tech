# 인공위성 첨단기술 지도 / Satellite Tech Atlas

공식 출처를 연결한 위성 기술·기업·제품·실증임무 탐색 웹앱입니다.

## 포함 기능

- 우주반도체·탑재 AI, 위성 광통신, 자율운용·분산 시스템, 소형 추진계, 전력·에너지 저장, 열제어·열소재, 지구관측·초분광 센서, 근접운용·도킹
- 선택 항목 중심의 관계 지도, 연결선별 근거
- 기업·제품 검색, 실증임무 비교, 날짜별 변화 기록
- 현재 브라우저에 저장하는 관심 목록 및 출처 포함 CSV 내보내기
- 출처 성격, 발표일·검토일, 목표·실증·개발사 주장 구분
- 지원 환경에서만 등록되는 읽기·탐색용 WebMCP 도구

## 실행과 배포

별도의 번들 빌드나 API 키가 없는 정적 웹앱입니다. `dist/`를 정적 호스팅에 올리면 됩니다. 개발 중에는 프로젝트 디렉터리에서 `python3 -m http.server 8080 --directory dist`로 실행할 수 있습니다.

**Render 연결은 [DEPLOY_RENDER.md](DEPLOY_RENDER.md)를 따르세요.** GitHub 저장소에 소스를 올린 뒤 Render의 Static Site 또는 Blueprint로 연결하면 됩니다. `render.yaml`에 배포 설정이 포함되어 있고, 빌드 단계에서는 Node.js로 데이터와 파일을 검증합니다. 의존성 설치, 시작 명령, 환경변수, 데이터베이스는 필요하지 않습니다.

## 데이터 파일

`dist/data.js`의 `sources`, `entities`, `links`, `events`가 원본 데이터입니다. 전체 데이터 구조는 브라우저의 `window.ATLAS`에서 읽을 수 있습니다.

`dist/evidence-data.js`는 원문을 확인한 근거 확장 데이터입니다. `data.js` 다음에 로드하며, 기존 항목에 출처를 추가하고 `evidence` 배열에 확인 주장·원문 위치·한계를 저장합니다. 관계의 `source`는 기존 대표 출처이고 `sources`는 추가 확인 출처를 포함합니다. 기존 검토일을 일괄 덮어쓰지 않으며, 상세 화면에서 항목과 원문별 검토일을 구분합니다.

2026-09-12 근거 확장에서는 **출처 18→49개**, **항목 85→110개**로 확대했습니다. 국가·지역 11개, 주장별 근거 31개를 포함하며 NASA·ESA 종합자료에 제조사 사양서, 개발기관 실증자료, 연구 논문, 실제 관측자료를 보강했습니다. 국내 KARI·TelePIX, 일본 JAXA·NICT, 인도 ISRO, 이탈리아 ASI, 독일 DLR, 호주 Melbourne 연구팀 등을 포함합니다. 수록 자료와 분야별 공백은 [근거 취합 현황](docs/EVIDENCE_COVERAGE.md)을 참고하세요.

‘근거 자료’ 화면에서 국가·지역 및 자료 유형을 필터링하고 확인 내용까지 다중 검색어로 검색할 수 있습니다. 상세 화면은 주장별 근거를 표시하며, 출처·항목 CSV에도 주장·확인 위치·한계가 포함됩니다. WebMCP의 `search_satellite_evidence_sources`는 같은 필터를 지원하며, `get_satellite_record_evidence`는 주장별 근거와 복수 관계 출처를 반환합니다.

1.3.0에서는 누락된 **SERVIS-1·SERVIS-2·RAPIS-1·TET-1**을 추가해 실증임무가 24개가 됐습니다. SERVIS는 COTS 우주환경 신뢰성 실증으로 분류하며 궤도상 서비스 임무와 구분합니다. Japan Space Systems와 Mitsubishi Electric의 원문으로 임무·개발 역할을 연결하고 `servis`, `SERVIS-2`, `서비스 2` 등으로 검색할 수 있습니다. RAPIS-1의 NBFPGA·GPRCS·TMSAP 실증장비도 연결했습니다. TET-1은 확인한 발사 자료에 맞춰 탑재·발사만 기록하며, SERVIS-3 사업 착수를 위성 발사로 추가하지 않았습니다. 현재 출처는 54개, 주장별 근거는 36개입니다.

`dist/research.js`는 화면과 WebMCP가 공유하는 검색 인덱스입니다. 이름·별칭·설명·상태·확인 범위·성능 항목·분야명에서 공백으로 나눈 검색어를 모두 포함하는 항목을 찾습니다. 다만 `서비스 1`, `SERVIS-2`처럼 등록된 이름과 번호를 입력하면 해당 식별자로 일치시켜 설명 속 연도로 인한 오탐을 방지합니다. 전체 분야를 기본으로 탐색하며, 분야 필터는 직접 연결된 다른 분야의 항목도 포함합니다. 관계 지도는 연결이 8개를 넘으면 페이지를 전환해 전체 연결을 확인할 수 있습니다.

첫 화면은 실증임무 탐색입니다. 카드에서 시험 대상과 확인 결과를 읽고 상세 화면에서 환경·구성, 부품별 실험, 해석 한계, 주요 기록과 원문을 확인합니다. `dist/mission-data.js`는 `evidence-data.js` 다음에 로드하며 24개 임무의 `demonstration`을 정의합니다. 정량 성과가 확인되지 않은 경우 탑재·발사 확인과 시험 계획을 구분합니다. 실증 설명은 검색 인덱스와 항목 CSV에도 포함됩니다. `dist/experience.css`는 카드와 임무 상세의 반응형 화면을 정의합니다.

분야를 추가할 때는 `fields`에 중심 기술을 지정하고, 출처가 있는 구체적인 제품·기관·임무와 연결합니다. 임무를 추가하면 출처가 연결된 `demonstration`도 작성합니다. 분야 수, 화면 목록과 WebMCP 허용 목록은 데이터에서 자동 생성됩니다. 검증기는 분야 중심·근거 연결·실증 상세·검색·WebMCP 입력을 검사합니다.

2026-09-12 확장판은 NASA 추진·전력·열제어 조사와 CPOD 임무 자료를 추가했습니다. 초분광 분야는 기존 Intuition-1 근거를 재분류했습니다. 기존 항목의 검토일을 보존하며, 데이터셋 날짜는 가장 최근 확장 검토일입니다. CPOD의 실증 목표 미달성도 기록하고, 서로 다른 NASA 페이지에서 상충하는 종료일은 확정하지 않았습니다. 이번 확장은 기술 분야 중심이며 국가별 산업 전수조사를 뜻하지 않습니다.

- `sources`: 발행기관, 자료 성격, 발표·갱신일(미기재 시 null), URL, 검토일, 해석 범위
- `entities`: 기술·기업/기관·제품·임무, 한글 별칭, 상태, 조건, 한계, 출처
- `links`: 양 끝 항목, 관계 유형, 근거 자료, 확인 범위
- `events`: 사건 또는 문서 발표 날짜, 기록 종류, 대상, 출처
- `evidence`: 대상 항목, 출처, 주장 종류, 확인 내용, 원문 내 위치, 확인 한계, 검토일

발행 계열 수는 독립 검증 횟수가 아닙니다. 개발팀의 논문·발표와 같은 사업 참여기관의 확인 자료는 서로 관련돼 있습니다. 특히 TelePIX의 PR Newswire 배포자료는 TelePIX의 주장으로 표시합니다. arXiv 원고를 수록했다는 이유만으로 동료심사나 독립 재현을 가정하지 않습니다. 원문을 열지 못한 후보 자료는 이번 추가 근거에서 제외했습니다.

초기 데이터는 선별한 공개자료의 스냅샷입니다. 자동 웹 수집, OpenAlex·DART 연결, AI 추출, 사용자 간 저장 동기화는 포함되어 있지 않습니다. 임의의 시장점유율·성장률·TRL·투자점수는 제공하지 않습니다. 기업 이름은 해당 자료의 표기를 보존하며, 현행 법인·인수관계 전체를 조사한 데이터가 아닙니다.

## 업데이트 원칙

1. 원문을 읽고 발행기관·발표일·검토일을 기록합니다.
2. 제품 버전과 실증 위성, 궤도·기간·시험조건을 확인할 수 있는 만큼 분리합니다.
3. 기술 분류, 공동사업 참여, 납품 계약을 서로 구분합니다.
4. 제조사 성능과 주관기관 실증 결과를 구분합니다.
5. 날짜가 월·연도까지만 알려졌다면 임의로 날짜를 보충하지 않습니다.
6. 출처와 기존 문구가 상충할 때 기록을 보존하고 한계를 명시합니다.

## 검증

`node scripts/validate.mjs`로 ID·URL 중복, 복수 출처 관계, 주장별 근거 연결, 날짜, 정적 자원, 검색·필터 및 WebMCP 입력을 점검합니다.

`node scripts/browser-check.mjs`는 실제 Chromium에서 1280px·390px 크기로 근거 목록·검색·필터·상세창·관계별 출처·CSV를 검사합니다. Windows Chrome/Edge를 자동 탐색하며 다른 환경은 `ATLAS_BROWSER`로 실행 파일 경로를 지정합니다. 별도 임시 프로필을 생성하고 검증 후 지웁니다. 실제 WebMCP 호스트 등록 및 외부 URL의 상시 가용성은 검증 범위에 포함하지 않습니다.

`node scripts/evidence-report.mjs`는 데이터에서 분야별 출처와 주장별 근거의 공백을 집계해 현황 문서를 갱신합니다.

## 사용한 자료

원문 링크와 발행기관은 앱의 ‘근거 자료’에서 제공합니다. 주요 자료는 NASA Small Spacecraft Technology 2026, ESA Φsat·Φsat-2·OPS-SAT·Proba-3, NASA Starling, KP Labs Intuition-1입니다. 원문 자료·로고의 권리는 각 소유자에게 있으며, 짧은 사실 요약과 출처 링크를 제공합니다.
